# Format and API contract

`Recorder(path, policy)` buffers only sanitized event snapshots, then seals a fresh directory. Context exit seals the captured run. `call(tool, arguments, invoke, depends_on=())` invokes `invoke(arguments)` once, captures its JSON result or exception and returns the original result during recording. `last_id` is the prior completed event identifier. Decorators bind Python function signatures and defaults; they do not infer dependency edges.

`Replay(path, policy, expected_root=None)` validates the whole directory before returning recorded values. The policy and private key must match. The same `call` shape is accepted but `invoke` is unused. Replay outputs include private Python string subclasses for pseudonym provenance; ordinary user strings resembling tokens are re-tokenized instead of being trusted. `finish()` enforces complete consumption. Context exit calls it after a normally completed workflow.

Each event contains exactly `id`, `tool`, `arguments`, `signature`, `depends_on`, `outcome`. IDs are `e000001` onwards. Dependencies are sorted unique earlier event IDs. Call signatures hash canonical `{tool, arguments}` after redaction. Outcomes contain either `{kind: return, value}` or `{kind: error, type, message}`. Error messages are whole-message HMAC pseudonyms; error types are a fixed built-in allowlist or `ToolError`, preventing arbitrary exception metadata from bypassing redaction.

Objects are stored at `objects/<sha256>.json`. `manifest.json` has exactly `format`, `policy_id`, `key_id`, `events` (ordered object digests), and `root`. The root hashes the other manifest fields. Policy ID hashes the redaction configuration; key ID is a domain-separated HMAC, never the key itself.

Canonicalization uses sorted-key compact UTF-8 JSON. Dictionary insertion order is irrelevant; array order, string content, booleans, integers and floating-point numbers retain distinct serialization, including signed floating-point zero. No NaN/infinity, bytes, tuples, datetimes, arbitrary classes, duplicate JSON keys or more than 100 nesting levels. This is a Python format contract, not an implementation of RFC 8785. Unicode strings are not normalized; callers must choose their normalization deliberately. Files are capped at 16 MiB, aggregate referenced evidence including the manifest at 64 MiB, and manifests at 100,000 events. Capture enforces its aggregate byte budget on each completed event; a result that exceeds it makes capture terminally failed and cannot be sealed. This occurs after invocation and cannot undo tool effects. Decoded Python structures can require more memory than serialized JSON. Public `events` inspection returns independent copies; modifying these cannot change persistence or playback.

Verification checks structural constraints even after a caller recomputes hashes; dependency cycles/forward references are invalid. Content addressing binds the serialized graph, not real-world causal truth. `compare` reports only first divergence; different policies or keys are incomparable. Export uses fixed ZIP timestamps and referenced objects, omitting unrelated files.

## JSON replay plans

`run_plan(path, plan, policy, expected_root=None)` and CLI `replay TRACE PLAN` require exactly `{"format": "replayseal/plan/v1", "calls": [...]}`. Each call requires `tool` and `arguments`, with optional `depends_on` (list of earlier event IDs, default `[]`) and `expect_error` (boolean, default `false`). Unknown keys are rejected. A normally returning event when `expect_error` is true, an unexpected recorded error, argument/order/edge differences and incomplete consumption are regressions. Invalid references, schemas, missing keys or evidence are operation errors.

Inside an arguments template, an object exactly `{"$result": "e000001", "pointer": "/customer_id"}` selects an earlier successful replay result. The empty pointer selects the entire result; array indices and `~0`/`~1` escapes are supported. Forward references, absent paths and references to error outcomes are invalid. `$result` is reserved within templates; there is no escape for a literal object using that key in this version. Selected values keep replay-issued pseudonym provenance. No expression evaluation, imports, automatic dependency inference, transformations of secrets, or tool execution occur. A referenced result does not automatically add a causal edge; list the intended edge in `depends_on`.

CLI loads plans and optional policy JSON with the same 16 MiB file and 100-level JSON limits and rejects duplicate keys. Omitted policy keys use SDK defaults. A plan is caller-owned input, not sanitized evidence: any raw literals in it must be protected separately. The CLI verifies a declared call sequence; SDK replay is needed to execute an actual orchestrator and test its branches.

## Architecture and complexity

`privacy.py` creates independent sanitized JSON snapshots; `core.py` handles capture/replay state, comparisons and ZIP export; `integrity.py` is a portable, standalone schema/content-address verifier; `plan.py` resolves prior outputs through a data-only plan; `cli.py` supplies payload-free summaries and stable exit codes.

For N events, B serialized bytes and D declared edges, capture/seal/verification process each event and referenced file once, with O(B + N + D) traversal/storage before dictionary/dependency sorting and regex costs. Canonical dict keys require O(k log k) sorting per object and each dependency list O(d log d); caller-defined regex runtime has no general linear bound. Incremental capture budget accounting is O(1) per event. Replay validates upfront, then visits each call once; both retain decoded events in memory, so this is a bounded fixture library, not a streaming trace database. Export adds an O(B) canonical byte copy and ZIP compression cost. Timings include actual filesystem costs in the [measurement report](BENCHMARKS.md).
